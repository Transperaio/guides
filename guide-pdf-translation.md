# A Practical Checklist for Translating PDFs with AI

PDFs are easy to read and awkward to translate. Text may be embedded or scanned, tables hold meaning in their layout, and one wrong step early on carries through to every language. This checklist walks through the steps that tend to matter. We build Transpera, so a few notes mention where a platform like ours fits, but the checklist works with any toolchain.

## 1. Know what kind of PDF you have

- [ ] Try selecting text in the file. If you can, the text is embedded.
- [ ] If you cannot, it is a scan or image and needs OCR (text extraction) first.
- [ ] Note any handwriting, stamps or low-resolution pages. These are where extraction is most likely to need a manual look.

## 2. Extract the text and tables before translating

- [ ] Run extraction and read a few pages of the output against the original.
- [ ] Check that tables kept their rows and columns. A table flattened into a paragraph translates badly.
- [ ] Fix extraction errors now. Translating a misread word only gives you a confident mistake in another language.

## 3. Prepare a small glossary

- [ ] List product names, brand terms and technical words that must stay consistent or stay untranslated.
- [ ] Decide the tone: formal or informal, and which regional variant of the target language you need.
- [ ] If your readers use a different script (for example Latin letters for a Hindi name), decide whether you need transliteration as well as translation.

## 4. Translate a sample first

- [ ] Pick two or three representative pages, including one with a table, and translate those.
- [ ] Ask a fluent reader to review them before you run the full document.
- [ ] Adjust the glossary based on what they find.

## 5. Translate the full document

- [ ] Keep the source file, the extracted text and the translated output together so you can trace any line back.
- [ ] For designed layouts such as brochures, check whether the source is an InDesign file. Translating the original file is often easier than rebuilding from a PDF.

## 6. Review with a human

- [ ] Have a qualified reviewer read the output, especially for legal, medical, financial or safety content.
- [ ] Check numbers, dates, units and names line by line.
- [ ] Check layout: text length changes between languages, so headings and table cells may overflow.

## 7. Publish and keep the loop

- [ ] Export in the format your readers need.
- [ ] Save reviewer corrections into the glossary for next time.
- [ ] If you translate often, consider connecting the steps (extract, translate, then optionally narrate) into a repeatable workflow rather than repeating them by hand.
